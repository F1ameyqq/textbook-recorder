# 暂停、回读与恢复

保存超时不能证明保存失败。平台可能已收到请求，而程序没有取得回执；此时重复新增会产生重复题。保留原题单、进度、锁、意图记录和日志，先核对当前失败任务。

## 正常暂停和关闭

暂停请求让执行器在安全边界停止，不撤销已经发送的保存，也不是立即断开连接。请求暂停后查看 `recorder:status`，等待任务确认终止。仍有 `pending` 或运行中的任务时不要关闭进程、重开客户端或手工编辑页面。

```powershell
npm run recorder:pause
npm run recorder:status
```

关闭服务只断开程序连接，保留用户页面和登录。关闭可能拒绝尚未确认终止的任务；先处理暂停和状态，不强行删除锁文件。

```powershell
npm run recorder:stop
```

## 先判断状态

| 状态或现象 | 下一步 |
| --- | --- |
| 达到 limit 或正常暂停后的 stopped | 确认任务终止、无错误、无写入锁及已处理题目回读通过，再用同一题单和 state 接续 |
| 尚未开始写入，题单校验失败 | 本地处理审校问题，再校验；不改历史证据 |
| 任务仍运行或控制请求超时 | 查看同一服务的状态，不再次提交执行命令 |
| 有成功回执，刷新回读失败 | 只读检查回执中的同一记录，不重新新增 |
| 请求已发出，回执缺失或结果未知 | 保持写入锁，读取失败任务的实际目录和记录 |
| 已有内容与题单不同 | 停止并交负责人判断，本版不自动覆盖 |
| 题目已完整存在且与题单相同 | 核对身份及来源后跳过，不重复写入 |

## 回读与核对

`verify` 对题单做只读核对；单题 `readback` 用于定位失败任务，`reconcile` 绑定原题单、原进度和该任务的保存意图，检查实际服务器记录。恢复只能核对当前失败范围，不能借另一份题单解除写入锁。

先在本地创建 `data/jobs/readback-args.json`，字段来自当前失败任务，不套用其他题的标识：

```json
{
  "manifest": "data/jobs/batch.json",
  "state": "data/jobs/progress.json",
  "taskId": "替换为原题单中失败任务的id",
  "capture": true
}
```

```powershell
npm run recorder:readback -- data/jobs/readback-args.json
```

准备 `data/jobs/recovery-args.json` 时保留相同的 `manifest`、`state`、`taskId`，去掉 `capture`，把 `pendingPath` 设为该失败任务原检查点中记录的保存意图文件。它不是新生成的意图，也不能指向其他失败任务。

```powershell
npm run recorder:recover -- data/jobs/recovery-args.json
npm run recorder:status
```

命令接受本地 JSON 参数文件，不接受任意浏览器脚本。恢复结果需等状态确认终止后判断；命令已受理不代表解锁成功。

恢复时需要完整目录记录与真实刷新回读，核对书号、章、节、题序、服务器身份、全文、来源和图片。已有记录数量或界面中的一段文字不足以证明未保存；缓存列表也不等于刷新后的服务器证据。

只有恢复证明明确确认同一记录已保存、完整内容一致且此前记录保持不变，才能记为已保存继续。工具无法确定时保持未知和写入锁，交负责人处理。不要手改 `attempts`、补造收据、把 `unknown` 改成 `not_saved`，也不要通过删除进度、令牌或锁来重试。

零保存请求的证明还需同一连接的实际观察及完整刷新基线。单凭磁盘意图写着零次或列表中未找到记录，不能解锁。本版恢复无法出具充分证明时可能持续保持锁；这不表示可以绕过锁重试。

## 恢复前保留材料

保留失败时的原题单和素材、进度、任务标识、时间、意图与回执、刷新回读和目录快照。修改审校内容应另存版本；冻结题单或资产变化会使旧进度失去对应关系，不能直接沿用执行。

请只把脱敏后的错误类型、软件版本和阶段说明交给维护者。原书图片、原始 HTML、账号、令牌、控制密钥及完整本地证据不要上传共享仓库。私有 GitHub 仓库仍属于另一份副本。

## 不在本版内的恢复

本版只做受约束的追加与结果核对，不提供批量删除、重建、任意 HTML 修复或未知保存后的自动重试。需要更改已有题目、重新分题或处理来源错误时，由负责人另行决定并在平台完成，不能把一次普通执行授权扩大为这些操作。

换书应使用新的独立工作目录，保留旧目录中的会话与证据。书号不匹配是保护检查，不能通过删旧状态或改成另一书号来解除。
