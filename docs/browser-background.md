# 后台浏览器模式

共享常驻服务的新实例默认使用 `focusMode: "background"`、`windowMode: "normal"`。probe、collect、execute、verify、readback、reconcile 和状态轮询沿用已绑定的教材 Page，不通过 MCP 选择标签，也不主动调用 `bringToFront()`，不自动最小化或搬动窗口。教材标签保持为所在普通窗口的活动标签，页面实际可见，但不要求系统窗口处于前台。编辑向指定 Page 发送浏览器输入，使用 browser-command，保留书籍、页面、目录、编辑器、选区、内容、保存回执和刷新回读检查。最小化模式须显式配置；该模式只最小化已经核对过的书页所在窗口，并读取窗口状态确认。

教材页面宜保留在独立 Edge 窗口，因为最小化作用于所在窗口。最小化可能使真实的 `visibilityState` 为 hidden、`document.hasFocus()` 为 false；这两个页面级状态不能单独作为最小化模式的拒绝条件。background/minimized 必须读取已绑定教材页所在窗口，确认唯一窗口身份及真实 minimized 状态，并在点击前后核对页面 URL、文档 timeOrigin 和窗口身份。foreground 仍要求真实可见性和文档焦点。background/normal 要求真实可见的文档及同一教材窗口处于 normal、maximized 或 fullscreen，允许真实的 `hasFocus()` 为 false；输入仍必须限定在指定编辑器的 activeElement 和选区内，并在输入前后核对同一窗口及文档身份，不激活系统窗口。

需要不抢前台的稳定录入时，使用默认的 background/normal。浏览器工具在操作后有网页定时器等待，最小化可能使该等待及平台自身初始化显著延迟；普通窗口模式不代表可以跳过真实预检、保存及刷新回读。切换后须先完成目标目录新基线和授权单题实际录入验收，再接续原任务。

后台普通窗口录入直接沿用已绑定的教材 Page，不自动创建窗口或跨窗口移动已连接的教材标签。实际跨窗口移动会断开浏览器调试连接，因此该路径已禁用。教材页宜在任务连接前放在独立普通窗口，并保持为该窗口的活动标签；业务操作不主动激活窗口或选择标签。可选窗口准备功能仅只读核对、复用已有合格窗口，条件不满足就停止；它不作为普通后台录入的启动步骤，也不改变草稿、保存或恢复状态。所有录入仍须通过真实文档可见性、窗口身份、编辑器和选区检查。

所有模式都必须保留控件唯一性、启用状态、稳定布局、视口内位置及真实命中检测；最小化不能豁免隐藏控件或 DOM 遮挡。最小化使用已核对控件的原生 `HTMLElement.focus()` / `click()` 激活普通界面流程，并观察目标点击；该点击为浏览器程序化激活，`isTrusted` 为 false，不能声称原生鼠标事件已投递。normal 模式仍用 Page.mouse 的可信鼠标事件。编辑继续使用浏览器编辑命令及原有输入事件，插入前同步检查目标编辑器为 activeElement，选区的两端均在该编辑器内。

禁止改写 visibilityState/hasFocus、启用焦点模拟来过检查、用 dispatchEvent 伪造编辑器输入、修改平台框架状态、自动恢复前台、使用系统剪贴板或保存 API。未知保存仍按原恢复流程处理。平台的完整录入按普通 UI 保存回执及刷新回读验收；本地窗口试验不能替代平台验收。

最小化模式追加时，编辑器 DOM 更新可能早于平台异步 change 回调，也不能仅靠失焦推断已经触发保存。执行器只读等待唯一绑定组件的题干、答案、书号、目录、草稿序号和来源页与已审内容一致，并确认本次尚未发出保存请求；随后保持题干编辑器焦点，单次激活页面真正的“保存”按钮。该激活不先聚焦按钮，记录两编辑器零次 blur，避免失焦保存和按钮保存同时触发。仍要求恰好一个保存请求、成功业务回执、刷新全文及原记录不变；不能补点保存或据本地文字清除未知结果。normal 模式继续沿用原失焦保存流程。

目录容器中的标签或图标可能有独立点击处理；必须激活真实命中检测得到的内层控件，而不是仅点击外层容器。来源页填值后，最小化模式通过激活另一侧来源输入框完成真实 blur/change；不依赖最小化时可能没有投递的 Tab。仍须确认两侧页码及对应原图实际加载成功，才能点击新增。

追加题的答案含 `analysis-separator` 时，background/minimized 使用同一受约束的浏览器原生 `insertHTML` 命令插入已审全文及平台固定分隔图片。它不依赖工具栏的键鼠选区缓存，不调用编辑器框架方法，不伪造输入事件，也不直接调用保存接口。图片地址、500px宽度和独立段落仍由固定渲染器生成，插入后检查图片实际加载、段落及原生强调，保存后检查完整服务器回读。报告应记录 `analysisInputMethod: browser-command-reviewed-native-image` 和零次解析按钮点击，不能声称点击了工具栏。normal 模式继续使用原生添加解析按钮；已有题的独立解析修正路径尚需另行验收，不能把追加验收扩大到所有修订。

Windows 官方扩展拒绝浏览器级 CDP 会话时，当前兼容桥优先从同一连接的 Page targetId 和顶层 sessionId 唯一映射 tabId。每个连接只创建一个明确 `active:false` 的扩展自有辅助标签，通过固定表达式实时读取该教材 tab 的窗口身份和状态，并在操作前后重新核对 tab、URL 和窗口；创建时的缓存窗口号只用于辅助标签放置，不能证明教材的当前窗口。最小化只调用已核对窗口的 `state:minimized`，不设置 focused，不选择标签。正文仍使用已绑定教材 Page，辅助标签不承担录入，不读取其正文、快照、控制台或令牌。

兼容桥不修改商店扩展或扩展命令允许列表。它使用受限的本地 Playwright 兼容补丁，固定版本及原文件完整哈希；升级或其他补丁导致不匹配时拒绝安装。仅在原任务安全结束、服务关闭后运行 `node scripts/install-extension-window-bridge.mjs --check` 检查，再运行同一脚本安装。原文件保存在本地 data 目录，补丁只加载本仓库的固定模块。生产验收以同书单题保存、刷新回读及旧记录不变为准，不能仅凭安装或本地测试解除恢复锁。

请求最小化仍至多一次。若 Chrome 返回的证明结构、教材 tab 和窗口身份均合法，但窗口尚未切换为 minimized，兼容桥在一秒单调时钟预算内仅重复读取同一窗口状态；每次读取也有剩余预算限制，迟到回执不能通过。身份、证明结构或接口错误立即停止；超时仍停止，不再次最小化、不恢复前台。错误只附固定分类及合法窗口状态，不输出任意页面内容或辅助页数据。

刷新后目录根节点超时会保存受限的只读目录诊断，并保留原错误停止。该诊断不增加刷新、选择、新增或保存重试，也不证明目标题未保存；恢复仍需要成功的真实刷新回读。已有记录的窗口校验修复可用只读核对验收，不能声称本轮又完成了保存试录。

常驻服务在 background/minimized 模式下对刷新后的目录根节点等待 90 秒，以容纳已观察到的约 60 秒页面初始化延迟；其他模式及章节、节目录仍等待 60 秒。根节点预算独立于编辑、保存及回读判断，不增加刷新或保存重试。只读 probe 超时时，终止结果包含受限的阶段和诊断文件路径，不能据此放行写入。

服务串行关闭时，先清理本连接确认身份的辅助标签，记录 `windowHelperCleanup` 回执，再处理自建空书页和断开 MCP。默认 context 关闭和 browser 关闭也先执行同一清理。创建、附着或清理结果不确定时保留页面，不重新创建或按 URL 批量删除。接口失败不回退到旧窗口号，也不借最小化操作解除题单暂停或写入锁。

未安装兼容桥时仍保留本地 Win32 路径：对已核对的书页临时设置随机标题标记，只操作唯一匹配的 Edge 窗口，随后恢复标题。该路径要求书页是窗口中已选中的标签；窗口最小化或标签未选中时，原生标题可能不反映新标记，找不到唯一窗口就停止。辅助进程隐藏运行，只支持读取状态或最小化，不能恢复或激活窗口。

首次扩展授权、连接或重新连接时官方扩展显示的页面，以及没有教材页时的创建操作，可能仍会显示或激活浏览器。后台模式抑制的是业务操作中重复的主动前置，不控制官方扩展或 Windows 的全部窗口行为。不要仅为了避免首次连接界面而跳过授权。

## 配置与切换

`config/recorder.json` 可设置 `"focusMode": "background"` 或 `"focusMode": "foreground"`，以及 `"windowMode": "minimized"` 或 `"windowMode": "normal"`。共享服务省略字段时使用 background/normal；省略 windowMode 时始终使用 normal。已显式配置的 minimized 保留原值，不自动迁移，运行中的服务也不改变模式。foreground/minimized 组合无效。直接构造旧适配器、一次性扩展入口仍保留 foreground/normal 默认值。原生剪贴板输入不能与 background 组合使用，需要该路径时显式使用 foreground/normal，保留原格式规则。

运行中的服务保留启动时的模式。`recorder:start` 只复用身份和模式一致的健康服务，不因配置改变而重启；模式不匹配时停止，不能假装切换成功。输出的 focusMode/windowMode 是实际模式，requestedFocusMode/requestedWindowMode 是本地请求模式。

只在当前任务已经安全结束、没有待核对保存后，按原关闭流程结束服务并正常启动新版。不要在任务中替换运行目录、已加载桥接或重启服务。旧桥接与请求模式不匹配时连接停止，不能把旧前置路径当成背景路径。模式切换不会重发任务或解除暂停、写入锁。

## 验证范围

本地自动测试可证明指定 Page 上的操作不调用主动前置，并检查编辑输入、回读、错误页面和遮挡拒绝。无头 Edge 的本地页面测试不会验证 Windows 窗口层级，也不代表真实录入平台验收。实际不抢前台的体验需要在任务结束后，用正常浏览器窗口的只读探测及获授权的单题保存回读验证；不能为本轮验证打断用户的现有任务。
