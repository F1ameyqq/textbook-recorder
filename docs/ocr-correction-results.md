# OCR 纠错 MAX：提示词 v2 的同样本结果

用户已选择 MAX 方案。本次发布包含[冻结提示词与参考配置](ocr-correction/README.md)，尚未接入或改变正在运行的录入任务。以下为 2026-10-20 完成的隔离试验结果，不包含原书题文、图片、答案或模型推理正文。

## 对照范围与结果

两轮使用相同的 50 道完整题、14 页原始 OCR、16 个 M 公式候选和两批各 25 题的 user 消息。仅修改 system 提示词；模型参数均为 `deepseek-flash`、启用思考、`reasoning_effort=max`、`max_tokens=65536`。本轮未重跑 OCR 或 GPU。

主要指标是整题对原图的忠实度：题干、选项、小问、作答空白、表格文字和数学内容均须完整；原书有意设置的错误选项也必须照录。配图保留原始像素，但图形重建和参考答案匹配不在评估范围内。

| 条件 | 整题忠实 | 比例 |
| --- | ---: | ---: |
| 原始 OCR | 6 / 50 | 12% |
| 旧 MAX 提示词 | 32 / 50 | 64% |
| MAX 提示词 v2 | 44 / 50 | 88% |

相对旧 MAX，12 道原来失败的整题变为忠实，原来正确的整题退化为 0 道。这不代表没有局部退步：3 道原来已失败的题出现 4 项新增错误或错误替换，已在原图复核中保留。

仍有 6 道题未通过严格指标：4 道涉及实字或引文转录，1 道涉及指数遗漏，1 道仅涉及等值数字表示改写。最后一类不是数学错误，但未保留印刷表示，因此仍按冻结规则计为失败。原始真值中的 6 条转录勘误另行记录，评分以原图为准；冻结源文件没有被改写。

M 的 13 / 16 指标来自前一轮已冻结的独立公式区域评价，本轮只是复用这些候选，不能称为新一轮 M 测量。该指标也不是 50 道完整题的准确率。

## 不确定性标记的覆盖

| v2 的 needsImage 与原图评价 | 题数 |
| --- | ---: |
| 已标记且有误 | 3 |
| 已标记但忠实 | 0 |
| 未标记却有误 | 3 |
| 未标记且忠实 | 44 |

因此只复核被标记的题，会漏掉 3 道已确认的错题。`needsImage=false`、JSON 协议通过和语言通顺均不能替代原图复核。

## 结论的适用边界

提示词 v2 是观察前轮这 50 道题的错误后调整的，再在同一批题上测试。88% 是同样本迭代结果，不是未见样本或留出集的泛化准确率。每个条件每批只有一次有效输出，随机输出差异也不能被排除；两轮模型别名和返回指纹相同，仍不构成永久固定后台快照的保证。

没有将原图、人工真值、参考答案或旧模型输出反馈给本轮 API，也没有对候选作本地修补。隔离检查记录 1,463 个保护文件及 83 个包版本未变；这只证明列明的文件和版本范围，不证明其他并行任务的运行时延完全不受影响，也不代表平台接入或整书验收。
