# 语文试题格式

用于后续语文教材的默认录入和验收。规则来自用户对书号 146965 试录结果的具体修订，并按用户要求推广到语文书；用户当前明确指定其他排版时按当前要求执行。先确认原图中的题目边界、文字、标点、拼音、答案及标记，再按下列格式转录。

## 题干、选项和填空

- 散文、阅读材料等正文自然段的段首缩进两个汉字宽度：文本前缀使用两个全角空格（U+3000，`\u3000\u3000`）。不能用三个半角空格近似；题号、题目问句、选项标签、答案和解析不统一加正文缩进。保留原有自然段。
- 选择题的空作答括号、正文中已有的空填字括号，括号内部用八个 ASCII 空格。保留原有半角或全角括号；含拼音、注释、编号或其他内容的括号不改成空括号，也不额外制造原书没有的答题括号。
- 每个完整 A/B/C/D 选项单独一个 text 块，同一选项的并列词语或词语加拼音组之间用八个 ASCII 空格；词语与它自身的拼音保持一个组，不能在汉字内部插入间隔。
- 将教材窄栏导致的同一选项硬换行合并，编辑器按宽度自然换行。诗歌、对联、戏剧台词和其他有意义的分行保留，不能因“横排”要求合并。
- 原书横排的多个填字提示保持同段，提示组之间用八个 ASCII 空格。多个已确认填空答案用 `parts`，相邻答案同样保留八个 ASCII 空格；需要上下标时用 `runs`。不能拆分、遗漏完整小问。
- 保留原书的读音、疑似错字、选项及官方答案，不能顺手将错误选项改对。疑点写入审校说明。

## 答案、解析和空段

- 答案与完整解析用既有 `analysis-separator` 分区，分隔线独占图片段；不额外插入纯空段来制造距离。
- 复合题答案与解析中的 `(1)`、`(2)` 等小问分别另起段落；独立的 A/B/C/D 选项讲解分别另起段落，保留全部解释和标点。正文中的普通列举或引用不机械拆段。
- 删除多余纯空白 text 块和人为连续空行，保留正常段落边界。平台为原生解析图片自动产生的必要结构不当作空文本段强行清除。

## 生成题单

语文题干和答案的所有 text 块显式设 `strictSpacing: true`，包含普通 `text`、`runs`、`parts` 及带 `emphasis` 的普通文本。正文段首保留两个 U+3000 全角空格；空括号和组间间隔仍使用八个 ASCII 空格，由现有渲染器转换为 NBSP 保持显示。全角空格只用于正文段首，不替代八空格间隔；不使用 Tab、CSS 缩进、合成加点字符或截图代替这些要求。具体块结构按[数据接口](schema.md)。

先定稿文字、空格和分段，再按最终文字计算 Unicode code point 范围：普通块使用 `block.text`，上下标组合块使用所有 `runs[].text` 顺序连接的全文，含题号、前缀、空格和上/下标字符。原自然段同时含注释上标与下划线或加点时，在同一个 text 块保留 `runs` 和块级 `emphasis`；不能删标记、拆段或截图绕过。对照原图分别核对题干和解析的每个加点、下划线及上下标位置；格式修订后重算范围，重新生成 mapping、草稿及绑定新哈希的审校决定。

区分原书的直线和波浪下划线：分别使用 `underline` 和 `underline-wavy`，不把断句波浪线改成普通直线或组合字符。窄栏造成的同自然段硬折行合并为连续文字，波浪线范围随最终文字重算，止于原书画线的最后一个字；未画线的句号等标点不纳入。待断句文字保持原文，不添加逗号或断句符号。波浪线可与同段的加点、注释上标及其他位置的普通下划线并存。

以下普通文本块仅示范两个汉字宽度的缩进和八个半角空格的间隔，不作为原书内容或生产题单。JSON 中 `\u3000` 解码后是一个全角空格：

```json
[
  {"type": "text", "text": "\u3000\u3000阅读材料的一个自然段。", "strictSpacing": true},
  {"type": "text", "text": "选择正确的一项（        ）", "strictSpacing": true},
  {"type": "text", "text": "A. 热忱（chén）        婆娑（suō）        锲而不舍（qì）", "strictSpacing": true}
]
```

## 保存后验收

首题试录和整批 `verify` 均检查真实保存后的刷新回读：

- 正文自然段段首恰好两个 U+3000 全角空格，并查看真实编辑器显示，确认缩进为两个汉字宽度；每个空作答括号及组间间隔恰好八个半角空格。
- 每个选项保持完整同段，没有教材窄栏残留的强制换行；有意义的原文分行仍完整。
- 答案、小问解析和独立选项解释的段落逐项对应，解析分隔线前后没有新增纯空段。
- 原书文字、标点、拼音、答案、加点和下划线完整，标记文字及范围正确；上/下标注号的类型和全文位置也逐项一致，组合格式仍保持原自然段。
- 波浪下划线的实际计算样式为 `underline` 加 `wavy`，普通下划线为 `underline` 加 `solid`；逐字符比较类型和范围，不能仅凭 `<u>` 标签或文字相同验收。首次使用先做单题真实保存和刷新回读，平台丢失或改变波浪样式时停止该批，保留原保存证据。

精确比较仅归一化 NBSP 与换行表示，保留 U+3000，不 `trim()` 段首或压缩间隔；不能以普通去空白文本相等代替格式验收。段首由三个 ASCII 空格改为两个 U+3000 时，Unicode code point 前缀长度由 3 变为 2，必须据最终文本重算加点和下划线范围。出现丢空格、错分段或丢标记时停止该批，保留证据，修订并重新审校后继续。
